# Граница публичной версии

Публичный репозиторий специально собран заново и не является урезанной копией
production Git-истории.

## Не публикуется

- рабочий Telegram-токен и идентификаторы администраторов;
- ключи и endpoint внешнего API;
- точный формат запросов и ответов API;
- алгоритм и интервалы прогнозирования;
- правила формирования игровых уведомлений;
- production-схема SQLite и миграции;
- административная панель и очередь массовых рассылок;
- журналы, резервные копии и пользовательские данные;
- systemd-конфигурация и параметры сервера.

## Публикуется

- безопасная доменная модель;
- интерфейсы компонентов;
- synthetic provider;
- fallback на сохранённое состояние;
- параллельный мониторинг с fault isolation;
- идемпотентный сервис доставки;
- автоматические тесты этих решений.

## Проверка перед публикацией

```powershell
python scripts/check.py
```

Команда компилирует пакет, запускает тесты и выполняет локальный поиск
высоковероятных секретов.
